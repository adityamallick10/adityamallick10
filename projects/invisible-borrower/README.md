# The Invisible Borrower
**An interactive educational financial-resilience dashboard**

[Open the HTML dashboard](./index.html)

This independent portfolio project examines whether alternative cash-flow indicators might inform discussions of financial inclusion and information asymmetry. It uses **500 deterministically generated synthetic profiles**, representing four illustrative borrower segments.

## Features
- Filter by segment and formal income documentation
- Explore sample records and summary metrics
- Transparent financial-resilience index
- Responsive, dependency-free HTML/CSS/JavaScript

## Method
`Index = 0.40 × income stability + 0.35 × savings buffer + 0.25 × (100 − debt burden)`

Each input is a simulated 0–100 indicator. The index is **not** a validated credit score or default-risk estimate. The 65 threshold is arbitrary. Documentation is not a scoring input.

## Limitations
No real borrower data, validation, calibration, fairness assessment, regulatory endorsement or loan decisions. Synthetic results cannot be generalized to Bangladesh.

## Running
Open `index.html` in a browser. No installation or external dependencies are required.
